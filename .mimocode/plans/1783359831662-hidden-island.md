# Plano: Testes Unitarios de Orders

## Arquivo: `tests/orders.test.ts`

### `beforeAll` — Setup de dados de teste

1. Limpar banco via `cleanDatabase()`
2. Criar `Category` (nome: "Teste", slug: "teste")
3. Criar `Product` com `isActive: true`, `basePrice: 100`, com 1 variante (sku: "ORD-001", stock: 10, attributes: {})
4. Registrar usuario via `POST /api/v1/auth/register` -> extrair `accessToken` -> `userToken`
5. Criar endereco via `POST /api/v1/users/me/addresses` -> extrair id -> `addressId`

### `afterAll`

1. `cleanDatabase()`
2. `prisma.$disconnect()`

### Cenarios de teste

#### 1. Checkout (`POST /api/v1/orders`)
- Adicionar item ao carrinho antes de cada teste de checkout
- **Deve criar pedido com dados validos** — envia `{ addressId, shippingMethod: "STANDARD", shippingFee: 15 }` -> espera 201, verifica `status: "success"`, `data.items.length > 0`, `data.status === "PENDING"`
- **Deve retornar 400 com carrinho vazio** — limpa carrinho, envia checkout -> espera 400
- **Deve retornar 404 com endereco inexistente** — envia `addressId` invalido -> espera 404

#### 2. Listagem e detalhe (`GET /api/v1/orders`, `GET /api/v1/orders/:orderId`)
- **Deve listar pedidos do usuario** — `GET /api/v1/orders` -> espera 200, `data.length >= 1`, meta presente
- **Deve retornar detalhe do pedido** — usa o `orderId` do checkout -> espera 200, verifica `data.items`, `data.address`, `data.statusHistory`
- **Deve retornar 404 para pedido inexistente** — envia UUID aleatorio -> espera 404
- **Deve retornar 401 sem token** -> espera 401

#### 3. Cancelamento (`POST /api/v1/orders/:orderId/cancel`)
- **Deve cancelar pedido com status PENDING** — envia `{ reason: "Mudou de ideia" }` -> espera 200, `data.status === "CANCELLED"`
- **Deve retornar 403 ao cancelar pedido ja cancelado** — cancela novamente -> espera 403
- **Deve retornar 404 para pedido inexistente** -> espera 404

### Estrutura final do arquivo

```
beforeAll -> cleanDatabase, criar category, product, registrar user, criar address
afterAll  -> cleanDatabase, prisma.$disconnect

```
